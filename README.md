## Problem Idea
This project aims to explore student performance using machine learning.
We will analyze study hours, sleep hours, attendance, and other factors
to understand student outcomes.

## Current Dataset Status
The dataset is currently a small sample dataset.
It contains student information such as study hours, sleep hours,
attendance, snacks, and pass/fail status.

## How to Run the Notebook
1. Open Google Colab.
2. Open the notebook from the notebooks folder.
3. Run all cells from top to bottom.
4. Check the outputs.

## Preliminary Results
The results are preliminary and may change after further analysis,
data preparation, and model improvement.
